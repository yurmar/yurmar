# Импорт плана проекта из Markdown

Проект блокнота можно создать из `.md`-файла: «Блокнот» → «Проекты» → **Импорт из MD**.
Файл описывает проект, этапы, задачи и ссылки. Ниже — формат и **промпт для ИИ**:
отдайте ИИ промпт и спеку, а полученный файл загрузите в импорт.

## Промпт для ИИ

Скопируйте текст ниже вместе со спекой проекта.

```text
Ты помогаешь планировать разработку. По приложенной спецификации составь план
проекта строго в формате Markdown, описанном ниже. Верни ТОЛЬКО содержимое .md-файла,
без пояснений и без обрамляющих ``` блоков.

ФОРМАТ

1. Файл начинается с блока свойств проекта между строками `---`:

---
name: Короткое название проекта
description: Одно–три предложения о цели и результате
status: planning
priority: normal
start_date: 2026-01-15
deadline: 2026-03-31
local_path: /путь/к/каталогу
repository_url: https://github.com/user/repo
technologies: [Laravel, React, PostgreSQL]
---

   - status: idea | planning | active | paused | completed | archived (по умолчанию planning)
   - priority: low | normal | high (по умолчанию normal)
   - даты только в формате YYYY-MM-DD; если даты нет в спецификации — строку не пиши
   - local_path и repository_url — только если они названы в спецификации
   - technologies — список в квадратных скобках через запятую

2. Каждый этап — заголовок второго уровня `## Название этапа`. Сразу под ним
   (до списка задач) можно указать свойства этапа, по одному на строку:

## Этап 1. Backend
description: Что должно быть готово по окончании этапа
status: todo
start_date: 2026-01-15
deadline: 2026-02-01

   - status: todo | in_progress | done (по умолчанию todo)

3. Задачи этапа — маркированный список с чекбоксами. Свойства задачи пишутся
   после названия через ` | `:

- [ ] Создать миграцию и модель | priority: high | due: 2026-01-20
- [ ] Написать feature-тесты | priority: normal
- [x] Уже сделанная задача | status: done

   - priority: low | normal | high (по умолчанию normal)
   - due: срок YYYY-MM-DD, только если он есть в спецификации
   - status: todo | in_progress | done | cancelled (`[x]` означает done)
   - пояснение к задаче — на следующей строке с отступом в два пробела

4. Задачи вне этапов — под заголовком `## Без этапа`.

5. Ссылки на материалы — под заголовком `## Ссылки`, по одной в строке:

## Ссылки
- Репозиторий: https://github.com/user/repo
- Спецификация: /Users/me/docs/spec.md

ПРАВИЛА СОСТАВЛЕНИЯ ПЛАНА

- Этапы идут в порядке выполнения; у каждого понятный результат.
- Задача — одно законченное действие на 1–4 часа работы, формулируй с глагола.
- Не придумывай даты, пути и ссылки, которых нет в спецификации.
- Покрой все требования спецификации; ничего не пропускай и не добавляй от себя.
- Критерии готовности из спецификации оформи отдельным последним этапом проверки.
- Статусы ставь `todo`, пока в спецификации не сказано, что работа уже сделана.
- Названия — до 255 символов; не используй символ `|` внутри названий задач.
```

## Формат (кратко)

| Что | Как |
|---|---|
| Проект | блок `---` в начале файла: `name`, `description`, `status`, `priority`, `start_date`, `deadline`, `local_path`, `repository_url`, `technologies` |
| Этап | заголовок `## Название`; под ним свойства `description`, `status`, `start_date`, `deadline` |
| Задача | `- [ ] Название \| priority: high \| due: 2026-01-20 \| status: in_progress` |
| Без этапа | заголовок `## Без этапа` |
| Ссылки | заголовок `## Ссылки`, элементы `- Название: URL-или-путь` либо `- [Название](URL)` |

Допустимы русские значения (`в работе`, `высокий`, `готово`) и даты `ДД.ММ.ГГГГ`.
Некорректные значения не ломают импорт: поле берётся по умолчанию, а в окне
импорта показываются предупреждения. Лимиты: до 50 этапов и 1000 задач в файле.

## Пример

```markdown
---
name: Сайт-визитка
description: Лендинг с формой обратной связи
status: planning
priority: high
start_date: 2026-02-01
technologies: [Laravel, React]
---

## Этап 1. Каркас
description: Рабочий каркас приложения
- [ ] Развернуть проект и подключить БД | priority: high
- [ ] Настроить сборку фронтенда

## Этап 2. Контент
deadline: 2026-02-20
- [ ] Сверстать главную страницу | due: 2026-02-10
  Адаптивно: 375, 768, 1440 px
- [ ] Подключить форму обратной связи

## Ссылки
- Макет: https://example.com/design
```
